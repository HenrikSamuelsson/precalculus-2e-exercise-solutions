\begin{problem}
What is the difference between a \emph{relation} and a \emph{function}?
\end{problem}

\begin{solution}
A \emph{relation} pairs input values with output values.
A \emph{function} is a special kind of relation in which each input is paired with \emph{exactly one} output. We say "the output is a function of the input".

For example, pairing people with the languages they speak is a relation. It is not a function because one person can speak more than one language, giving a single input more than one output.

Pairing people with their dates of birth is a function because each person has exactly one date of birth.
\end{solution}

\begin{answer}
A \emph{relation} pairs input values with output values.
A \emph{function} is a relation in which each possible input value leads to exactly one output value.
\end{answer}
